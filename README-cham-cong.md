# Chấm công Teachable Machine (giống bài mẫu)

## Cách dùng

1. Mở https://playground.raise.mit.edu/create/
2. **File → Load from your computer** → chọn `cham-cong-teachable-machine.sb3`
3. Dán link Teachable Machine vào khối `use model`
4. Bấm **cờ xanh**
5. Bấm phím **`a`** để bắt đầu chấm công
6. Lần lượt nhìn camera: **Trang**, **Thỏ**, **rắn**
7. Hết 10 giây → báo đủ người hoặc vắng

## Class trên Teachable Machine phải đúng

- `Trang`
- `Thỏ`
- `rắn`

## Phím

- **cờ xanh**: tải model
- **a**: bắt đầu chấm công
- **space**: tắt camera
